# 537P3682 — Xerox 16/8 EM-II (Disk Expansion Module) controller box ROM

`537p3682.rom` — 4096 bytes, crc32 `88f30a00`, sha1 `54d205e5a7ed80feb7cd06eddc863110fc655dde`.

This is the **dumped controller ROM of the 16/8 Expansion Module (EM-II / DEM),
Xerox product F89** — the box the v5.0 monitor calls `rgd5` (the 5.25" rigid-disk
unit). It carries the **WD1002-05 hard-disk/floppy driver** that the monitor's
`ddskld` loader pages in at boot.

## Provenance
Hex-decoded from `537P3682.ROM` on master disks **box18/B18D9** (the "824 BIOS TEST
DISK … HORTON 12/23/81") and **box13/B13D16**; the two copies decode byte-identical
(verified). B13D16 also holds a full disassembly, **`537P3682.Z80`** (ORG `$F380`).

## Identification (conclusive)
- Loads/runs at **`$F380`** — the host RAM-resident box-driver region (beside the
  SA1403D box driver's `$F360`). Disassembly head = `DRVTBL`:
  `dw SELERR, dw DSKDRV, dw SELERR×5, dw FFFF` → binary first bytes
  `2a f5 c1 f4 2a f5 …` (= the table), then `DPBASE` at `$F390`.
- **`DSKDRV` is at `$F4C1`** — exactly the `DSKDVR equ 0F4C1h` entry named by the
  EM-II's own `INIT.MAC` (box16/B16D2, "INIT for the Expansion Module", W. Gee 1983).
- Drives the **WD1002-05 task-file registers at I/O ports `$A8–$AF`**
  (`$A8` data, `$A9` error, `$AA` sec-count, `$AB` sec-number, `$AC/$AD` cyl lo/hi,
  `$AE` SDH = sector-size/head/drive-select, `$AF` status/command). e.g. drive
  deselect = `OUT (0AEH),0D7H`; `DSKDRV` validates unit (<8) → `SELECT`(`$F4FC`) or
  `RDWR`(`$F6A5`), 10× retry via `RESTR`(`$F68F`).
- Uses the 16/8 monitor structures: `CONFIG`=`$F03C`, `RGDBUF`=`$E000`,
  `DIRBUF`=`$FC80`, the `CHKnn`/`ALLnn` CP/M directory vectors.

The same task file serves the EM-II's ST-506 rigid (Shugart "712", 11 MB) **and**
its 5.25" floppies (SDH drive-select; `m.floppy = 00011000b` in INIT.MAC). The EM-II
controller board is a **WD1002-05** (WD1010 Winchester+floppy combo); see
`../README.md` and the `INIT.MAC` register equates.
